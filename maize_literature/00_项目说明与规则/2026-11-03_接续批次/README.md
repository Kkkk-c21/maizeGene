## 运行增量流程

需要Python 3.9或以上版本。先安装依赖：

```powershell
python -m pip install -r "maize_literature/03_脚本/07_增量补查映射与标签/requirements.txt"
python "maize_literature/03_脚本/07_增量补查映射与标签/run_pipeline.py" --source "<本地数据根目录>" --output "maize_literature/01_数据/接续输出/delivery_v1_0"
```

`--source`支持整理后的六类目录及原平铺结构，递归定位以下文件。每个名称必须唯一；不要把多个同名批次副本混放在输入根目录。输入只读，输出必须另存。

| 必需文件 | 用途 |
|---|---|
| `papers_master_v1_4.csv` | 固定72,467篇主表，不重做清洗或相关性筛选 |
| `paper_classification_v1_4.csv` | 原分类，原样保留 |
| `gene_trait_evidence_candidates_v1_2_reviewed.csv` | 3,214条人工合并源表 |
| `gene_trait_evidence_candidates_v1_3_optimized.csv` | 原质量字段与稳定记录ID |
| `neo4j_query_table_data_2026-11-2(1).csv` | 5,000基因参考；列为gene_id、symbol、aliases |
| 优化表所在目录的`quality_report.md` | 旧质量报告，随新报告附存 |

缓存按输入哈希、脚本、规则和批大小隔离；中断后使用相同命令恢复。流水线先生成七主文件与基本报告，再补充训练排除、逐文件核验和打包。输出包、缓存及原文证据仅留本地。打包时会复制输入主表，所以输出包也不能上传GitHub。

旧分类脚本不由增量流程调用。`05_无API初筛与分类/01_初版`和`02_v1.3`保留当时的相对输入路径，只作为历史快照；需要历史复现时先阅读脚本的INPUT/OUT。v1.4脚本具有输入路径及`--outdir`参数。

v1.3候选优化脚本可通过`--candidates`、`--papers-zip`、`--gene-reference`、`--output`指定本地文件。其`--papers-zip`需要包含根层`papers_master_v1_4.csv`的已有本地ZIP，不是本批次增量流程的依赖。
