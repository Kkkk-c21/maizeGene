# MaizeGene 证据分类口径 v1.4（2026-11-02）

本口径只用于对主表题名和摘要进行规则候选初筛。自动标签不是最终人工裁定，也不表示已抽取出有效的基因—性状断言。

## 相关性标签（与证据类别分开）

- **M1**：摘要/题名显示玉米是实际研究对象，包括玉米植株、材料、组织、基因/蛋白、性状或玉米来源材料的直接实验研究。
- **M2**：玉米是研究情境或介质，研究核心落在与玉米有关的人类/动物、害虫、食品健康等外部对象。
- **N**：没有可支持的玉米研究内容，玉米仅为无关比较物、背景或未出现。
- **U_rel**：题名摘要不足以判定。

自动相关性只提供候选。出现玉米词本身不等于 M1；在摘要中顺带提及玉米也不等于 M2。

## 证据标签（允许多标签）

- **A**：直接玉米基因/蛋白功能实验候选。需同时出现可识别的玉米基因/蛋白符号、直接实验操作或生化测定，以及明确玉米研究对象；转基因/突变词若指害虫、微生物、其他物种或纯计算模拟，不计 A。表达差异本身不自动成为 A。
- **B**：具体基因/等位变异/遗传变异与明确性状之间的遗传关联候选。只报告群体变异、等位基因频率或有害变异负荷，不计 B。
- **C**：作者实际开展的 GWAS/QTL、转录/表达、单细胞、染色质、表观、蛋白质组、代谢组等组学证据候选。基因家族表达分析也可触发 C；表达变化不代表因果。
- **D**：作者实际开展的基因/蛋白序列、结构、同源、系统发育、基因家族、计算预测或群体变异计算分析候选。一般农艺统计不计 D。
- **E**：可复用的基因组/分子数据库、工具、方法或构建资源候选。家族鉴定本身不自动成为 E；专利/启动子资源可候选 E，若摘要没有功能结果不自动加 A。
- **R**：综述、系统综述、范围综述或荟萃分析。若没有 A–E 基因功能证据，可同时标 X。
- **X**：非玉米基因功能核心研究，如食品加工、饲料/营养、农艺管理、环境、病虫害生态等；当存在 A–E 候选时，规则不自动追加 X。
- **U**：文本信息不足或规则无法判断。

## 决策限制

1. 仅以现有题名和摘要为证据，不推断未报告的实验、结果或因果关系。
2. 支持片段必须来自摘要原文；无 API 的自动化仅可提供候选句，不作改写式证据。
3. 不强制把基因名称映射成 ID；无可靠标识时留空或 unresolved。
4. 本版本未连接生成式模型，也未导入/修改 Neo4j。
5. 规则候选供排序和复核，不可直接用作模型的最终金标准标签。
