# 玉米文献 CSV 保守清洗规则 v1

日期：2026-10-28

## 输入与输出边界

- 原始输入：`maize_papers.csv`。
- 原始文件保持不变，清洗结果写入新文件 `maize_papers_cleaned_v1.csv`。
- 清洗脚本在目标文件或报告文件已存在时拒绝运行，不覆盖任何已有结果。
- 全程逐行处理，不把 225,007 条记录整体载入内存。

## v1 执行的处理

1. 保留全部 225,007 条记录，不做相关性删除。
2. 保留原有 8 个字段，并追加：
   - `source_record_key`：`SOURCE:record_id`，作为稳定记录键。
   - `cleaning_flags`：分号分隔的缺失、格式及年份提示。
3. DOI 去首尾空白、去 `doi:` 或 DOI URL 前缀并转小写。
4. `pmid`、`year`、`source`、`record_id`、`retrieved_at` 去首尾空白；`source` 转大写。
5. 标题与摘要先解码 HTML 实体，再只删除已确认的格式标签：`i`、`b`、`em`、`italic`、`sub`、`sup`。
6. 标题与摘要连续空白折叠为单个空格。
7. 2027 年记录只添加 `year_2027_review` 标志，不删除、不改年份。
8. 编码替代字符 `�` 只添加标志，不擅自猜测或替换原字。

## v1 明确不做的处理

- 不按标题年代或相关性删除文献。
- 不把 36 条复核样本的标签比例外推到全库。
- 不把 `U` 当作负例。
- 不使用单独 `record_id` 去重；稳定键为 `(source, record_id)`。
- 不按标准化标题自动去重；相同标题仅作为候选重复。
- 不删除或改写统计学比较符号，如 `p < 0.05`、`x > y`。
- 不修改或补写 PMID、DOI、年份、基因 ID 和 B73 版本映射。
- 不把 S0450 的候选 B73 v5 ID `Zm00001eb220940` 写入正式真值；其 3 条证据仍待人工复核。

## 后续阶段

清洗 v1 完成并验收后，再独立开展相关性筛选。筛选应使用人工复核规则 A/B/C/D/E/R/X/U，保存筛选理由与来源；训练集、校准集和独立测试集必须分开，并记录人工审核来源。
