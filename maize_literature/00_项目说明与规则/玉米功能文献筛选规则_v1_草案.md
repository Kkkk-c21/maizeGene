# 玉米功能文献筛选规则 v1（草案，待批准）

日期：2026-10-28  
状态：仅用于规则确认，尚未用于 225,007 条全库分类。

## 1. 这份规则要解决什么

第一步只判断“一篇文献是否值得进入玉米内源基因功能知识库，以及属于哪一类证据”。

第二步才从保留的文献中提取具体关系，例如：哪个基因、什么实验、在哪种材料和条件下、观察到什么结果。文献标签不能代替逐条证据提取。

原始文献记录始终保留。`X` 只是“不进入当前核心库”，不是删除；`U` 是待核实，不能当作负例。

主要误判模式：

- 把“出现基因词、蛋白词、过表达词”误当成 A。
- 把纯农艺、加工、气候、花粉扩散、动物营养或其他物种研究误当成 B、D、E、R。

- 把“dataset”“review”等文章类型词直接当成项目相关性。

## 3. 标签定义（按工作簿原意整理）

### A：直接功能

存在玉米基因或玉米来源蛋白层面的直接实验。必须确认研究物种、基因或蛋白身份、实际实验和测得结果。单独出现 `transgenic`、`binding`、`protein`、`overexpression` 等词不足以判 A。

已复核示例：玉米突变体、玉米基因过表达、玉米来源重组蛋白酶学、启动子报告实验、蛋白纯化和亚细胞定位。

### B：表型性状

存在可识别的玉米基因或等位基因与表型之间的关系。纯施肥、气候、栽培或加工造成的产量和性状变化，不作为单基因证据。

A 与 B 可以并存。本批约定：两者都成立时，以 A 为主标签、B 为补充标签。

### C：关联证据

QTL、GWAS、表达或群体关联证据。QTL 区间证据先挂在 QTL 或区间节点，不能自动指派给区间内某个候选基因。

### D：计算证据

序列、系统发育、同源或基因功能模型支持。通用气候模型、加工模型、花粉扩散模型或其他与基因功能无关的模型不属于 D。

### E：数据资源

与玉米基因功能有关的基因组、组学、网络或数据库资源。文章带有 `dataset`、`data`、`database` 等词，不等于自动属于 E。

### R：相关综述

主题确实能帮助梳理玉米基因功能并追溯原始研究的综述。综述中的陈述不能直接记作本篇的实验事实。与核心问题无关的综述或荟萃分析仍判 X。

### X：不入当前核心库

标题、摘要或全文已显示文章超出“玉米内源基因功能”核心范围。原始记录继续保留，只是不进入当前核心关系提取队列。

常见 X：

- 其他植物、动物、人、微生物或害虫是实际实验对象。
- 玉米只作为饲料、油、淀粉、培养材料、比较对象、间作背景或样品来源。
- 纯农艺管理、施肥、气候、加工、营养、毒理、法规、食品或区域产量研究。
- 玉米伴生微生物具有功能，但没有玉米宿主基因证据。

### U：待核实

缺摘要、摘要截断、全文缺失、物种或分子身份不清，或证据只能停留在酶活、蛋白组分、材料或专利用途主张层面。必须记录具体缺口。U 不能作为已确认负例，也不能靠标题摘要猜补完整因果链。

## 4. 建议的逐篇判断顺序

### 第一步：确认实际研究对象

先问：被实验、测序、扰动或测量的究竟是玉米基因/蛋白，还是伴生微生物、害虫、其他作物、动物或人？

如果玉米只作为背景材料，通常判 X；如果摘要不足以确认，判 U。

### 第二步：确认能否形成可追溯的关系

寻找玉米基因、等位基因、蛋白或 QTL 与以下对象之间的明确关系：

- 分子功能或酶活
- 生物过程或调控
- 亚细胞定位
- 表达响应
- 生化或形态表型
- 农艺性状
- 群体或区间关联
- 可复用的功能数据资源

摘要没有基因名不自动等于无关；但也不能从品种名、QPM 名称、酶名或背景知识猜出具体基因。

### 第三步：按实际证据赋标签

- 有直接基因/蛋白实验：A。
- 只有明确的基因/等位基因—表型关系：B。
- QTL、GWAS、表达或群体关联：C。
- 序列、同源、系统发育或功能预测：D。
- 基因功能相关数据资源：E。
- 可追溯原始研究的相关综述：R。
- 明确超出核心范围：X。
- 信息不足：U。

除“A 与 B 同时成立时 A 为主”之外，历史材料没有给出可靠的通用标签优先级。其他多标签情况应保留补充标签，不自行发明优先顺序。

### 第四步：限制结论强度

- 过表达后含量增加，可写成“过表达后提高某含量”，不能自动写成“该蛋白直接催化合成”。
- 亚细胞共定位支持定位，不单独证明催化功能。
- QTL 支持区间与性状关联，不自动证明区间内某基因因果。
- 异源表达的玉米蛋白酶学可以支持蛋白功能，但必须记录实验宿主，不能直接外推整株性状。
- 同一论文中的多个组织、多个实验或多条转基因株系不是多篇独立文献证据。
- 旧基因 ID 与 B73 v5 的关系未经核实时保持空白或标为候选，不按名字相似强行映射。

## 5. 36 篇人工记录支持什么

合并标签：X 20、A 5、C 3、U 3、E 2、R 1、D 1、B 1。

这 36 篇支持：

- 上述标签的工作定义和常见边界例子。
- “先判断研究对象，再判断证据类型”的流程。
- A/B、C/单基因、E/普通数据论文、R/普通综述、X/U 等关键边界。
- 用保守的关系句记录实际观察，不补写未验证机制。

这 36 篇不支持：

- 推断全库中各标签的比例。
- 声称旧电脑预标或未来分类器的准确率、召回率。
- 把 U 当负例训练。
- 认为 5 个工作簿是 5 次独立复核。
- 把 S0450 的 3 条证据当成 3 篇独立文献支持。

## 6. 目前仍不清楚、需要批准的事项

2. 未映射到具体基因的玉米酶活、蛋白组分或材料层证据，是长期保留 U，还是建立独立“辅助证据层”？
3. 专利只有序列、定位、转化流程或用途主张，但没有核实表型挑战、对照和量化结果时，是否统一保留 U？历史样例支持这样做。
4. 是否接受“A 为主、B/C 为补充”的多标签约定？目前只有 A/B 的主次约定明确，其他组合不应擅自设优先级。
5. S0450 的候选 v5 模型 `Zm00001eb220940` 仍需独立序列和一对一映射核验，不能先当确定 ID。
